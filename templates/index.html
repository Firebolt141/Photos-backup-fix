Overview
Runs entirely on this computer. Nothing is uploaded.

Put the right dates back on your photos.

Restore the dates and places Google Takeout stripped out, sort everything into tidy dated folders, and repair a backup drive in a few clicks.

What do you want to do?

Good to know

  • Preview first. Every tool has a preview mode that shows exactly what would happen and writes nothing except a report.
  • Your originals are safe. Takeout and filename sorting only copy. The two drive tools edit in place, and ask before they do.
  • Stop any time. Run again later and finished files are skipped, so big exports can be done in parts.
  • Every run is recorded. A spreadsheet-friendly report (CSV + JSON) is saved in a _photofix folder.
  • Works with the Android app. Same folder layout (2024/March/March_15), so both can share one drive.
